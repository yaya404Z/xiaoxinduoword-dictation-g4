# 单词听写 · 小学四年级英语

给小学生练英语单词听写的小程序：点词听发音、听写填空、积分奖惩。
电脑、手机、网页三端同源，全按钮操作（触摸屏也能用，不需要回车键）。

## 功能

- 词表：外研版（三起）2024 新教材 四年级上册 Unit 1–6
- 发音：有道在线发音优先，系统语音兜底，带撇号的词也能读
- 听写：听音填空，**答对 +1 积分，答错扣 3**
- 积分：存本机，原来攒的会保留
- 积分商城：暂未开放
- 清除积分：需要密码，按钮会疯狂乱窜，第 20 下才抓到
- 自动检查更新：打开时比对最新发布，有新版本在顶部提示「去升级 / 以后再说」

## 自己发新版

1. 改好程序后，把文件名带上版本号：`setup-1.0.3.exe`、`app-1.0.3.apk`
2. 在 Releases 里发一个新的 tag（如 `1.0.3`），把这两个文件传进附件
3. 已装的老版本打开就会自动提示升级
