# 单词听写 · 小学四年级英语

一个给小学生练英语单词听写的小程序：点词听发音、听写填空、积分奖励、清除积分密码保护。
电脑、手机、网页三端同源，界面全按钮操作（触摸屏也能用，不需要键盘回车）。

## 功能

- 词表：外研版（三起）2024 新教材 四年级上册 Unit 1–6
- 发音：有道在线发音优先，系统语音兜底，带撇号的词也能读
- 听写：听音填空，答对 +10 积分，积分存本机
- 积分商城：暂未开放
- 清除积分：需要输入密码，按钮会疯狂乱窜，第 20 下才抓到
- 自动检查更新：打开时比对仓库里带版本号的安装包，有新版本就在顶部提示

## 版本规则

发新版只要上传名字里带版本号的文件即可，程序会自动识别最新那个：

- 安卓：`app-1.0.2.apk`
